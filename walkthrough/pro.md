# Zovo Pro tools

Each tool has 1 free try on this computer. After that, Zovo Pro is USD 19 once for the Pro tools in every Zovo extension.

- Generate sample XML: pick a global element and get a sample document that keeps the schema's rules, written next to the schema.
- Validate XML: check an XML file against its schema set with libxml2 inside VS Code. Errors go to the Problems panel.
- HTML documentation: a folder of HTML pages for the schema set, one page per element and type with its diagram.

Run them from the Command Palette, from the right-click menu of a file in the Explorer, or from the row at the end of the viewer toolbar.
